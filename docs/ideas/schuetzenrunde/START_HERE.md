# TE MiniGames – Schützenrunde

Diese ZIP enthält die vom Nutzer bereitgestellte Spezifikation unverändert sowie extrahierte Markdown-/JSON-Dateien aus der Spezifikation.

## Start
1. `00_ORIGINAL_SPEZIFIKATION.txt` vollständig lesen.
2. Danach die extrahierten Dateien lesen.
3. Die Entwicklungs-KI muss vor Codeänderungen die bestehende TE-MiniGames-Codebasis analysieren.
4. Keine externe KI für das Gameplay einsetzen.
