# Finde den Imposter

**Status: vollständig umgesetzt (02.09.2026)** — Einzelheiten in
[STATUS.md](./STATUS.md).

Die Spezifikation kam am 01.09.2026 von Thomas: geheimes Wort, Hinweise,
Abstimmung, letzte Chance, eigene Kategorien, ~1000 Wörter, 7 Modi. Alles
davon ist gebaut, dazu der Online-Mehrspieler.

Zwei Punkte der Spezifikation sehen heute anders aus, beide auf Thomas'
ausdrücklichen Wunsch vom 02.09.2026:

- **Getippte Hinweise gibt es nicht mehr.** Statt jeder sein Hinweiswort
  einzutippen, wird geredet. Der Bildschirm sagt nur noch, wer anfängt.
- **Kein Punktesystem, keine Rangliste.** Das Spiel speichert bewusst kein
  Ergebnis, vergibt keine XP und taucht in keiner Rangliste auf – wer
  gewonnen hat, sieht man am Tisch.

Seit dem 04.09.2026 ist der Zettel abgearbeitet: **Duell** läuft auch online
(jedes Team stimmt getrennt ab), und **eigene Kategorien** lassen sich für
Online-Runden hochladen – der Server zieht das Wort weiterhin selbst, der
Gastgeber erfährt nur nicht, welches es geworden ist.
